# P7: Design Tokens and Typography System in CSS

## Aim
To create a small, consistent design system using CSS custom properties (design tokens) for colours, spacing, and typography.

## Procedure
1. Create the `P7` folder with `index.html` and `style.css`.
2. Link the stylesheet in the HTML document.
3. Define reusable values inside the CSS `:root` selector.
4. Use `var(--token-name)` wherever a token is needed.
5. Change one token, such as the primary colour or spacing, and observe how multiple elements update.

## Concepts used
CSS custom properties, the `:root` selector, `var()`, typography scale, spacing scale, and reusable colour values.

## Expected result
A sample page whose headings, text, card, and link share a consistent visual style controlled by CSS variables.

## Conclusion
I used CSS design tokens to keep design values reusable and make the page easier to maintain.
