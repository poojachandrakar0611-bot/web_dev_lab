# P12: Portfolio Projects Grid with Advanced CSS Grid

## Aim
Create a portfolio projects section using advanced CSS Grid features such as responsive tracks, spanning, and automatic row sizing.

## Concepts
- `repeat()` creates repeated grid tracks.
- `minmax()` sets a minimum and maximum track size.
- `fr` distributes available space.
- `grid-column: span 2` and `grid-row: span 2` make a project card span multiple tracks.
- Media queries adjust the number of columns for smaller screens.

## Files
- `index.html` — portfolio heading and project cards.
- `style.css` — advanced grid layout and responsive rules.

## Procedure
1. Save both files in a folder named `P12`.
2. Open `index.html` in a browser.
3. Observe how the featured project takes more space than the other cards.
4. Resize the browser to see the grid change from three columns to two and then one.

## Expected result
A responsive portfolio grid with a featured card and supporting project cards.

## Conclusion
I practised building a flexible project gallery using repeated tracks, minimum sizes, and grid item spanning.
