# P1: Project Folder and Terminal Navigation

## Aim
To create a project folder and practise navigating between folders using terminal commands.

## Commands and procedure

Open Terminal (or the VS Code terminal) and run these commands one by one.

```bash
# 1. Display the current working directory
pwd

# 2. List the files and folders in the current location
ls

# 3. Create the main folder for the lab work
mkdir web-development-lab

# 4. Move into the new folder
cd web-development-lab

# 5. Create folders for the practical files
mkdir P1 P2 P3 P4

# 6. Confirm the current location and list the folders
pwd
ls

# 7. Move one level back
cd ..

# 8. Enter the project folder again
cd web-development-lab
```

## Explanation

| Command | Purpose |
|---|---|
| `pwd` | Prints the path of the current working directory. |
| `ls` | Lists files and folders in the current directory. |
| `mkdir` | Creates a new directory. |
| `cd folder-name` | Moves into the specified directory. |
| `cd ..` | Moves to the parent directory. |

## Expected result
A folder named `web-development-lab` is created. Inside it, four folders named `P1`, `P2`, `P3`, and `P4` are visible.

## Conclusion
I practised checking my current location, viewing directory contents, creating folders, and moving between directories using the terminal.
