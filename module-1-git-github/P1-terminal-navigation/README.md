# P1 — Project folder and terminal navigation

This practical records the basic terminal commands used to create a project folder and move between folders.

```bash
pwd
ls
mkdir web-development-i-lab
cd web-development-i-lab
mkdir module-1-git-github module-2-html-css module-3-css-layout
cd ..
cd web-development-i-lab
```

`pwd` prints the current working directory, `ls` lists its contents, `mkdir` creates a directory, and `cd` changes the current directory.

## What I practised

- Checking where I am in the terminal.
- Listing files and folders.
- Creating a project directory.
- Moving into and out of directories.
