# P11: Newspaper-Style Three-Column Layout with CSS Grid

## Aim
To create a newspaper-style page with a three-column layout using CSS Grid.

## Procedure
1. Create the `P11` folder and add the HTML and CSS files.
2. Add a masthead with the newspaper name, date, and tagline.
3. Place story articles inside a grid container.
4. Define three columns with `grid-template-columns`.
5. Make the lead story span two rows using `grid-row`.
6. Add media queries to reduce the number of columns on smaller screens.

## Concepts used
CSS Grid, fractional units, column gaps, grid item placement, row spanning, and responsive breakpoints.

## Expected result
A newspaper page with a prominent lead story and supporting stories arranged in three columns on wide screens and fewer columns on smaller screens.

## Conclusion
I used CSS Grid to create a newspaper layout and responsive media queries to make it suitable for different screen widths.
