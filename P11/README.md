# P11: Newspaper-Style Three-Column Layout with CSS Grid

## Aim
Create a newspaper-style page with a three-column story layout using CSS Grid.

## Concepts
- `display: grid` creates a grid container.
- `grid-template-columns` defines the column tracks.
- The `fr` unit distributes available space between tracks.
- `gap` sets the space between grid items.
- `grid-column` and `grid-row` allow an item to span tracks.
- Media queries reduce the number of columns on smaller screens.

## Files
- `index.html` — masthead and news-style story cards.
- `style.css` — three-column grid and responsive breakpoints.

## Procedure
1. Save both files in a folder named `P11`.
2. Open the HTML file in a browser.
3. Observe the lead story spanning two rows.
4. Reduce the browser width to see the grid change to two columns and then one column.

## Expected result
A newspaper-inspired page with a masthead, one prominent lead story, and supporting stories arranged in columns.

## Conclusion
I used CSS Grid tracks and spanning to create a newspaper layout that responds to screen size.
