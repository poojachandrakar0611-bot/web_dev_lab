# P6: Full Portfolio Page Structure in Semantic HTML

## Aim
To build a complete student portfolio page using semantic HTML sections and a linked CSS file.

## Files
- `index.html`: navigation, hero, about, skills, projects, contact, and footer.
- `style.css`: layout, typography, cards, and responsive styling.

## Procedure
1. Create the `P6` folder and add both files.
2. Link `style.css` from the HTML `head`.
3. Add a header with a brand name and navigation links.
4. Add a main area containing the portfolio sections.
5. Use matching section IDs and navigation href values.
6. Open the page in a browser and test each navigation link.

## Concepts used
Semantic elements, anchor links, sections, articles, lists, Flexbox, and a media query.

## Expected result
A portfolio page with working in-page navigation and sections for About, Skills, Projects, and Contact.

## Conclusion
I structured a portfolio using semantic HTML and used CSS to create a readable layout that adapts to smaller screens.
