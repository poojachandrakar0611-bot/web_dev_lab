# Programming for Web Development – I Laboratory

This repository contains the 13 practical exercises from the Programming for Web Development-I Laboratory sheet. Each practical is kept in its own clearly named folder at the repository root.

## Practicals

| Folder | Practical |
|---|---|
| [P1](P1/) | Project folder and terminal navigation |
| [P2](P2/) | Portfolio repo with an initial commit |
| [P3](P3/) | Feature-branch Git workflow |
| [P4](P4/) | GitHub README and version tags |
| [P5](P5/) | Semantic bio page |
| [P6](P6/) | Full portfolio page structure in semantic HTML |
| [P7](P7/) | Design tokens and typography system in CSS |
| [P8](P8/) | Sticky navbar and card overlay using CSS positioning |
| [P9](P9/) | Responsive navbar and card grid using Flexbox |

| [P12](P12/) | Portfolio projects grid with advanced CSS Grid |
| [P13](P13/) | Choosing between Flexbox and Grid for a shared layout |

## How to run the HTML and CSS practicals

1. Open this repository in VS Code.
2. Open the folder for the practical you want to view.
3. Open its `index.html` file in a browser, or use the Live Server extension.
4. Keep the practical's `index.html` and `style.css` files together in the same folder.

The Git and GitHub practicals (P1–P4) include their commands and procedure in their README files.
