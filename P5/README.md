# P5: Semantic Bio Page

## Aim
To create a personal biography webpage using semantic HTML elements.

## Files
- `index.html`: page content and semantic structure.
- `style.css`: page presentation.

## Procedure
1. Create a folder named `P5`.
2. Create `index.html` and `style.css` inside it.
3. Add the HTML structure shown in `index.html`.
4. Link the stylesheet in the document's `head`.
5. Open `index.html` in a browser and check the page.

## Concepts used
- `header` for introductory page content.
- `main` for the primary content.
- `section` to group related information.
- `footer` for closing information.
- Headings and lists to organise the biography.

## Expected result
A simple biography page with an introduction, interests, and personal goal, presented with CSS.

## Conclusion
I created a bio page and practised using semantic HTML elements to give webpage content a clear structure.
